# fmvgmins2ins
These Python codes can extract instruments in VGM File.

|File|Description|
|------|---|
|oplvgmins2wopl.py|This can extract OPL instruments to WOPL and OPLI in OPL Family VGM File.|
|opnvgmins2tfi.py|This can extract OPN instruments to TFI in OPN(YM2203) VGM File.|

## How to use
    python example.py example.vgm
